Cada post tiene una cabecera fija y debajo una barra de pestañas. La cabecera lleva el título, la bajada, la fecha y el tiempo de lectura. Las pestañas dividen el contenido en subpáginas.

Para qué sirve cada pestaña

Artículo es el texto que se lee de corrido: la pregunta, qué se probó y qué salió. Es la pestaña que se abre por defecto.

Experimento reúne los paneles interactivos y los resultados con datos reales. Código tiene los fragmentos para reproducirlo. Notas guarda fuentes, enlaces y lo que quedó pendiente.

Las pestañas son libres. Un post puede tener solo dos, o agregar otras como «Datos», «Prompts» o «Versión 2». Si un post no necesita pestañas, se borra la barra y las secciones, y el contenido va directo.

Un enlace por pestaña

Cada pestaña tiene su propia dirección: la del post más # y el nombre de la pestaña, por ejemplo posts/plantilla/#experimento. Así se puede compartir directamente el experimento o el código de un post.

Los paneles comparten un mismo formato: título, controles y resultado. Este calcula en vivo un softmax con temperatura sobre cuatro opciones.

Los números de un post real salen de los archivos de resultados del experimento, nunca escritos a mano.

El código va en bloques con botón para copiar.

softmax.py
import numpy as np

def softmax(z, T=1.0):
    z = np.array(z) / T
    p = np.exp(z - z.max())
    return p / p.sum()
